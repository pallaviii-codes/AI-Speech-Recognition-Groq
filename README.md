# AI Speech Recognition using Groq API

## About the Project
This project explores AI-based speech recognition using Python,
the Groq API, and the Whisper Large V3 model.

## Technologies Used
- Python
- Groq API
- Whisper Large V3
- Google Colab

## Features
- Groq API integration
- Speech recognition
- Audio-to-text processing
- AI-based speech processing

## Model Used
Whisper Large V3
